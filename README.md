# Share&Rent

Учебный MVP сервиса аренды вещей. Каталог, карточка вещи, создание объявления и заявки используют серверные API и базу D1. Данные примеров помечены как демонстрационные. Авторизация, изоляция пользователей, модерация, подтверждение заявок и реальная сделка не реализованы. Используйте только тестовые данные.

Стек: React, Next-совместимый Vinext, TypeScript, Cloudflare D1, Drizzle ORM. Хранилище Supabase не подключено.

Команды: `npm install`, `npm run db:generate`, `npm run build`. Для работы базы требуется привязка D1 `DB` и применение миграций из каталога drizzle.

При создании заявки сервер может создать сделку в Битрикс24 через входящий вебхук. Для этого в серверных настройках задаётся секрет BITRIX_WEBHOOK (базовый адрес вебхука, без метода API). Адрес нельзя добавлять в репозиторий. Если передача не удалась, заявка остаётся в базе сайта; автоматический повтор не настроен. Интеграция предназначена для тестовых данных.
